# Alliance Facility Group

A responsive cleaning-service website and dashboard starter built with React, Vite, React Router, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

The generated `dist` directory can be deployed to Vercel or Netlify. Configure the host to rewrite all application routes to `index.html`.

## Included

- Premium responsive marketing pages
- Corporate quote and residential booking flows
- Client and admin dashboard views
- FAQ, contact, gallery, careers, blog, legal, and 404 pages
- Page transitions, scroll reveals, counters, loading states, and reduced-motion support

Forms and dashboards currently use demo data. Connect them to an authenticated API before accepting real customer information.
